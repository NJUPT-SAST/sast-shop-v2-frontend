# 移动端空状态与错误展示

2026-10-06 走查范围：移动端所有 `Empty`、`LoadFailure`、错误边界、列表分页失败，以及表单和交易中的失败提示。

内容缺失使用对应场景的空状态；读取失败使用加载失败插画。两者均直接放在内容区，不额外包背景卡片。第一次加载失败在剩余页面或 Drawer 内容区居中；已有缓存的更新失败和加载更多失败使用紧凑提示，继续展示已加载内容。加载失败保留 `role="alert"` 以及标题、描述关联，装饰插画不重复朗读。

## 空状态复核

现货无库存使用货架插画，搜索无结果使用搜索插画，订单和账单使用订单插画，无店铺使用店铺插画，无商品模板使用模板插画，无地址使用地址插画，无收款码使用收款码插画，跑腿清单使用购物篮插画，跑腿需求为空使用团长插画。无效详情链接沿用搜索插画及业务返回入口，兼容直接打开详情的场景。未知地址和其他页面读取异常补充根级空状态及错误边界，避免展示框架默认页面。成功提交、任务完成及取消继续用结果状态符号。

无库存、无订单等自然空状态不增加无效返回按钮。已确认需要支持直达链接的详情缺失、店铺模板缺失及读取失败保留业务返回入口。清空搜索、创建模板和唯一的创建店铺入口继续保留；团购页已提供创建店铺按钮，空状态不重复添加。

## 保持局部展示的失败提示

条码字段校验、扫码取消或鉴权失败、创建店铺、模板保存或删除、图片上传、地址保存及上架写入失败，保留在字段或操作旁。支付结果待确认、流水号状态待确认、采购或分发结果待核实、账单生成异常、缺少支付信息及不可接单状态，继续显示业务提示和已有恢复保护。

这些状态仍有可用表单或订单内容，不能用整页插画替换，也不能为结果不明的写入添加直接重发按钮。图片加载失败继续使用 `ManagedImage` 占位；登录和飞书环境提示继续使用已有专用插画及认证恢复入口。
